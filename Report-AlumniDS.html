2. REST API Endpoints

POST /api/v1/auth/login — Login, returns JWT token
POST /api/v1/alumni — Register new alumnus
GET /api/v1/alumni/count — Count alumni (integer)
GET /api/v1/alumni — Get all alumni
GET /api/v1/alumni/search?name=&enrollment_year=&graduation_year=&country=&page=&format= — Search alumni (format: json | xml)
GET /api/v1/alumni/{id}/jobs — Get jobs of alumnus
PUT /api/v1/alumni/{id}/jobs/{jobId} — Update job (απαιτείται JWT + ownership)
DELETE /api/v1/alumni/{id}/jobs/{jobId} — Delete job (απαιτείται JWT + ownership)

Σημείωση: Όλα τα GET endpoints εκτός των auth/alumni login & register απαιτούν JWT Bearer token στο Authorization header. Τα endpoints 6,7 ελέγχουν και authorization (ownership).
